# Documentos do jogo original

Cópia, a 2026-10-05, dos documentos de design de `ruiguitos/horde-breaker`
(branch `feat-unity-migration`, commit `22277fa`). Servem como **referência
histórica** — intenção, inspirações, lições e números já discutidos — e
**não são especificação** do remake.

Ficaram de fora, de propósito, os documentos que descrevem a implementação
antiga (ARCHITECTURE, PROJECT_REFERENCE, PROGRESS, TODO, planos de
implementação): o remake não toma o código antigo como referência.

| Ficheiro | Para que serve no remake |
|---|---|
| `GDD.md` | Visão, loop, classes, inimigos, progressão e HUD do original |
| `PROJECT_AUDIT.md` | Diagnóstico de 2026-09-06: o que existia, lacunas e prioridades |
| `INSPIRATIONS.md` | Comparação com DRG Survivor, RoR2, YAZS, WWZ, KF2 e critérios de HUD |
| `ARCHIPELAGO_GAMEPLAY_PLAN.md` | Estrutura da expedição, papel de cada ilha, base por tiers |
| `MAP_DESIGN.md` | Princípios de legibilidade, ritmo e risco espacial (os números são da arena antiga) |
| `HUD_AND_OUTER_MISSIONS.md` | Missões curtas das ilhas opcionais e HUD |
| `SCRAP_EXPEDITION_PLAN.md` | Uso do Scrap durante a expedição |
| `CONTENT_EXPANSION_PLAN.md` | Matriz de classes, armas e skills |
| `SKILL_TREE_EXPANSION_PROPOSAL.md` | Árvore de 36 nós do Recruit |
| `ROADMAP.md` | Prioridades e milestones do original |

Os links internos destes ficheiros apontam para caminhos do repositório
original e podem não funcionar aqui.
